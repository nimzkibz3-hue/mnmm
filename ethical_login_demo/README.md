# PhotoShare Login Demo — Ethical Cybersecurity Training

A responsive, Instagram-inspired **fictional login mockup** for learning to recognize phishing.

## Safety by design

- Does not save, log, or transmit form entries.
- Does not connect to an authentication service.
- Clears the demo fields when the button is pressed.
- Shows a security-awareness lesson instead of signing anyone in.
- Uses fictional branding and clearly labels the page as a training demo.

**Never enter real passwords, verification codes, or other private information into a demo page.**

## Run locally

1. Download and unzip this project.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site; the Pages settings will show the site URL.

## Project files

- `index.html` — page structure and demo form
- `style.css` — responsive layout and styling
- `script.js` — safe demo behavior
